# Common-component analyses

Run from the repository root after the core preparation documented in `docs/core.md`. `outputs/cache` below is the **flat** core output directory. Its 189 rows must retain the same participant order across arrays, metadata, folds and BDF paths. All participant-level files below are generated locally and contain sensitive measurements; they are not included in the repository.

## Dependencies

Power, archive and template comparisons use NumPy and SciPy. Residualization and the covariate adapter additionally use pandas and scikit-learn. Auxiliary extraction requires MNE. The component analyses used Python 3.14.3, NumPy 2.3.4, SciPy 1.16.3, pandas 2.3.3, scikit-learn 1.8.0 and MNE 1.10.2. RMS model training is a separate environment: **PyTorch 2.0.1+cu118, NumPy 1.26.4**, CUDA GPU; SciPy and scikit-learn supply reporting. The RMS script rejects a different training runtime. Preserve the supplied EEGNet implementation and the same baseline runtime.

## Commands

```sh
python -B analysis/components/auxiliary.py --input outputs/cache/ordered_bdf_paths.json --output outputs/auxiliary
python -B analysis/components/power.py --input outputs/cache --indices outputs/auxiliary/eligible_indices.json --output outputs/power
python -B analysis/components/prepare_covariates.py --input outputs/cache --power outputs/power/features.npz --auxiliary outputs/auxiliary/features.json --output outputs/covariates.csv
python -B analysis/components/residualize.py --input outputs/covariates.csv --folds outputs/cache/folds.json --output outputs/covariates
python -B analysis/components/ecg.py --input outputs/auxiliary/features.json --labels outputs/cache/labels.npy --indices outputs/auxiliary/eligible_indices.json --output outputs/ecg
python -B analysis/components/archive.py --input outputs/power/features.npz --groups outputs/cache/archive_groups.npy --indices outputs/auxiliary/eligible_indices.json --output outputs/archive
```

Auxiliary extraction reads the calibrated Erbs and MASS channels from the ordered BDF paths emitted by core preparation. Relative paths are interpreted relative to the JSON file. The source sampling rate must be 500 Hz and source physical units microvolts; MNE volt data are multiplied by one million. The QRS detector runs on the full record at thresholds 0.6 and 0.4. Eligibility uses only 4–64 seconds: finite nonflat channels, at least 30 events, median-RR rate 40–160 bpm, at least 90% RR intervals in 0.375–1.5 seconds, detector F1 at least 0.8 within 50 ms, count/RR-rate disagreement at most 15%, and finite MASS power. The expected eligible roster is 186, without further exclusions after visual inspection. F1 compares two settings of the same detector and does not validate true beats. Saved outputs are `features.json`, `events.json` and `eligible_indices.json`.

Power inputs are `linked_basic.npy` and `average_basic.npy`, float32 microvolt tensors of shape `(189,15,19,800)`; `labels.npy` is binary (0 control, 1 ADHD). `quality_features.npy` has six columns named in `manifest.json`. Welch uses 200 Hz, periodic Hann length 400, 200-sample overlap, constant detrending, density scaling and mean averaging. Band bins are integrated at 0.5 Hz; boundaries are left-closed/right-open with the 40-Hz bin included. Common is the float32 spatial mean. CAR power averages channels before logging. Each window power is floored at 1e-12 before log10, then averaged across windows; total 1–40 Hz is integrated before logging. Mean-log power differs from log-mean power. `features.npz` contains the 14 columns named in `names`, plus `labels`. `results.json` reports all component/band contrasts, Hedges g, geometric ratios, descriptive variance/power fractions and numerical identities for primary 186 and overlapping 189 cohorts. Diagnosis-stratified participant multinomial draws use 20,000 replicates, seed 20261116, shared across features. Power ratio expected for primary total common power: about 0.571 [0.480,0.679].

The adapter creates every CSV column directly from the generated metadata, power and auxiliary files. Required CSV columns are `label`, numeric binary `eligible`, `age_years`, `sex_male`, five `{delta,theta,alpha,beta,gamma}_log10_power` columns, the six quality columns listed in the script, `heart_rate_bpm`, `mass_log10_power_60_90` and `beat_quality_f1`. CSV rows remain the full 189; eligibility intersects the original five participant folds, without repartitioning. The adapter uses 17 significant digits to preserve round trips.

Residualization uses training-only median imputation plus missing indicators, standardization, Ridge alpha 1, subtraction and a second standardization, then balanced logistic regression C 1 (10,000 maximum iterations, seed 17). B0 is unadjusted; BAge adjusts age/sex; BD adds six quality measures; BH adds heart rate to BD; BM adds MASS power/F1 to BD. HRonly and MQonly are covariate-only comparisons. The seven arms require 35 logistic and 20 Ridge fits; no bootstrap refits. `results.json` contains AUC/loss and paired intervals; `fit_parameters.json`, `oof.json` and `coefficients.json` record fitted transformations, probabilities and slopes in standardized and original feature units. B0/BAge/BD AUCs are approximately 0.802/0.800/0.712. Original-unit slopes divide classifier coefficients by original-feature SD and, where applicable, residual SD. They hold nuisance covariates fixed and are not marginal effects.

MASS uses 15 four-second windows from 4–64 seconds, 1000-sample Hann segments with 500 overlap, inclusive 60–90 Hz bins, per-window log10 power and window averaging. Erbs templates use full-record 5–35 Hz zero-double FIR filtering (10-second Hann firwin2, 0.5-Hz transitions), detected events with complete -0.2 to +0.4 second support inside the interval, and per-epoch -0.2 to -0.1 second baseline subtraction. The comparison uses the peak-to-peak amplitude of the arithmetic mean template, not mean individual R-wave amplitude. `ecg/results.json` uses sequential within-diagnosis integer bootstrap draws with one seed-20261116 generator across primary and overlapping cohorts. Expected primary geometric amplitude ratio is about 1.014 [0.843,1.209]. Invalid full-cohort amplitudes stop only that overlapping comparison, without deleting records.

Archive input `archive_groups.npy` comes from core preparation (`annotated`/`unannotated` strings); labels identify controls. Numeric codes 0 control, 1 annotated ADHD, 2 unannotated ADHD are also accepted. Expected group counts are 131/39/16 in primary 186 and 133/40/16 in overlapping 189. All six common/CAR total-power contrasts share independently sampled within-group multinomial counts (20,000, seed 20261116). `results.json` contains log differences and transformed ratios/intervals. Primary common ratios are approximately 0.533 annotated/control, 0.679 unannotated/control and 0.785 annotated/unannotated. Annotation is not a verified treatment/site/device measurement.

## Participant RMS sensitivity

```sh
python -B analysis/components/rms.py train --input outputs/cache --output outputs/rms
python -B analysis/components/rms.py report --input outputs/cache --baseline outputs/training --output outputs/rms
```

Training creates ten new fits and refuses to overwrite an existing fold result. Each participant is divided by one float64-computed RMS over all 15×19×800 values, separately for linked-mastoid and CAR, before float32 conversion. The original training-fold scalar normalization remains. Original five folds, seed `1109+100*fold+50000`, batch size four, 30 epochs, weighted BCE, Adam lr 0.001/weight decay 0.0001 and original EEGNet constraints are preserved. Outputs are ten checkpoints and ten fold JSONs plus per-participant RMS JSONs. No model training is performed by `report`.

The baseline directory contains the single-initialization 30-epoch source files `fixed30_eegnet_linked_basic_seed1109_split20261109_fold0.json` through fold4 and the corresponding `average_basic` files. Each has `test_ids` matching the original fold and `logits_by_epoch["30"]`. These are produced by the core seed-1109 training plan. Report outputs `results.json` and `oof.json`, applying sigmoid to logits. A shared diagnosis-stratified 20,000-replicate multinomial bootstrap, seed 20261116, estimates paired AUC changes and the change in reference contrast. Expected original/normalized AUCs: linked 0.838/0.860 and CAR 0.661/0.681; contrast change about 0.002 [-0.052,0.057]. These conditional intervals omit training/split uncertainty and do not establish equivalence or physical signal origin.
