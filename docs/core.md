# Core signal and classification analysis

These scripts implement the signal preparation and source-cohort classification analyses in the article and Online Resource 1. Commands run from the repository root. Replace the example input paths with the downloaded TDBRAIN V3.1 release. Outputs are generated locally; participant records and EEG are not distributed with the code.

## Reconstruct the cohort

Required inputs are the released `TDBRAIN_participants_V3.xlsx` workbook, the released BDF recordings, and their JSON sidecars. No precomputed participant roster or recording inventory is required.

```sh
python analysis/core/inventory.py --data data/tdbrain --output outputs/metadata/inventory.csv
python analysis/core/census.py --metadata data/tdbrain/TDBRAIN_participants_V3.xlsx --inventory outputs/metadata/inventory.csv --output outputs/metadata/census.csv
python analysis/core/cohort.py --census outputs/metadata/census.csv --output outputs/metadata/roster.csv
python analysis/core/prepare.py --data data/tdbrain --roster outputs/metadata/roster.csv --inventory outputs/metadata/inventory.csv --output outputs/cache
```

`inventory.py` opens BDF headers without loading signal samples. It records all observed sessions before the earliest numeric session is selected. Structural support requires a readable, nonempty recording with finite positive sampling frequency, positive sample and channel counts, and duration above one second. Resting eyes-closed eligibility then requires at least 60 seconds, 500 Hz and all 19 specified scalp channels. The census resolves participant-level diagnoses across metadata rows, excludes ambiguous diagnoses, selects the first valid age and recorded sex in session order, and retains adults aged 18–55. Cases have formal ADHD; controls have formal HEALTHY and congruent HEALTHY indication. ADD and undocumented diagnoses are not substituted for ADHD. Participant identifiers determine stable ascending order. The cohort command checks the release-specific 193-person target (56 ADHD and 137 controls).

For the release used in the article, the entire reconstructed roster has SHA-256 `c309e2e118dfdece08db22ed2a1bf72fa4fdad2297dd6cf746ec2ece2ec5b79f`. A different count or hash requires a dataset/version reconciliation before interpreting results.

Preparation filters each continuous recording with the fourth-order 1–40 Hz Butterworth SOS filter, resamples 500 to 200 Hz, then takes 4–64 seconds. Signals are expressed in microvolts. A single gross-failure exclusion is applied before constructing all four linked-mastoid/CAR × uncorrected/ocular-regressed representations. The ocular regressors are VPVA−VNVB and HPHL−HNHR; least squares uses `rcond=1e-8`. The expected retained cohort is 189 (56 ADHD, 133 controls). Every tensor has shape `[participant,15,19,800]`. The fixed channel order is recorded in `manifest.json`.

The cache contains the four representation arrays, `labels.npy`, `folds.json`, window-averaged log-bandpower arrays, six quality features, source hashes and locally generated cohort metadata. It also contains `ordered_bdf_paths.json` for auxiliary-signal extraction and `archive_groups.npy` for archive-annotation comparisons. The latter stores annotation presence; diagnosis is carried separately in `labels.npy`. All participant-level intermediates are generated by these commands.

## Neural models

```sh
python analysis/core/plan.py --input outputs/cache --output outputs/core_plan.json --modules core
python analysis/core/train.py --input outputs/cache --plan outputs/core_plan.json --output outputs/training --device cuda
```

`core` includes EEGNet and the temporal CNN, the four processing arms, three initializations (1109, 2209, 3309), and the same five outer folds. Training uses all windows of four participants per batch, training-derived scalar RMS normalization, class-weighted binary cross-entropy, Adam (learning rate 0.001, weight decay 0.0001), and 30 epochs. A participant logit is the mean window logit. The effective refit initialization is seed + 100 × fold + 50000. EEGNet has 1,809 parameters; the temporal CNN has 24,545. `model.py` provides `EEGNet`; `models.py` provides `make_model('eegnet')` and `make_model('temporal_cnn')`.

For exact reported neural comparisons use PyTorch 2.0.1+cu118 and NumPy 1.26.4. `--device cpu` supports execution on CPU but does not imply bitwise agreement with CUDA. Training records software versions, code/plan/input hashes, curves, held-out logits, checkpoint hashes and normalization scale. Each checkpoint contains `state`, `scale`, `train_ids`, `test_ids`, `job`, `epoch` and `hashes`. Instantiate the recorded architecture, load `state`, and evaluate the matching tensor divided by `scale`. Ensemble probabilities are averaged after applying the logistic function separately to each initialization's out-of-fold logits. Repeated jobs verify input and checkpoint hashes before reuse.

`--max-jobs 1` limits a command to one new outer model; it is an execution limit, not a changed analysis specification.

## Reported training sensitivities

```sh
python analysis/core/plan.py --input outputs/cache --output outputs/sensitivity_plan.json --modules stopping long partitions matched quality duration common laplacian label_null
python analysis/core/train.py --input outputs/cache --plan outputs/sensitivity_plan.json --output outputs/sensitivity_training --device cuda
```

The participant RMS control uses `analysis/components/rms.py`; see the component documentation. The module list is explicit so expensive comparisons can be run separately. The generator does not inspect predictions. It writes transformed arrays into the supplied cache and records cohort restrictions in the plan.

| Module | Specification |
| --- | --- |
| `stopping` | Class-balanced validation BCE; stratified 20% inner holdout; maximum 30 epochs; patience eight; earliest strict minimum; normalization refitted on outer training set |
| `long` | Seed 1109, EEGNet, 100 epochs; checkpoints 10, 20, 30, 60, 100 |
| `partitions` | Alternative five-fold seeds 20261110 and 20261111; EEGNet seed 1109 |
| `matched` | Maximum-cardinality, minimum-age-distance same-sex matching within three years; 56 pairs; pair members remain in the same fold |
| `quality` | At most 10% channel-windows above 200 microvolts peak-to-peak; original folds restricted to 187 eligible people |
| `duration` | Largest mixed-diagnosis exact recording-duration stratum, 121 seconds; 155 people, unchanged 60-second analysis interval; three initializations, two uncorrected references |
| `common` | Repeat the linked-mastoid channel mean across 19 channels; verify subtraction equals CAR; fresh common-only and residual models, three initializations |
| `laplacian` | Standard 10–20 MNE CSD, automatic sphere, lambda2=1e-5, stiffness=4, 50 Legendre terms; microvolts converted to volts; reference-equivalence check |
| `label_null` | Reported label-randomization control: permute only outer-training labels with seed 77119+fold, preserving held-out labels |

The surface Laplacian is a spatial representation in volts per square metre. It is not another physical voltage reference. Matching and duration restrictions do not establish acquisition-source equivalence. Confidence intervals condition on fitted models; matched comparisons must resample whole pairs.

## Spectral and metadata predictors

```sh
python analysis/core/spectral.py --input outputs/cache --output outputs/spectral --nested --permutations 199 --plan outputs/sensitivity_plan.json
```

The output `oof_predictions.npz` contains held-out probabilities for the reported spectral, demographic, quality and archive predictors, their combined and train-only residualized variants, common-only/common-plus-CAR predictors, alternative partitions, and low-four/high-two/all-six common-band vectors. The optional plan supplies matching/quality restrictions and Laplacian representations. `--nested` selects C from 0.01, 0.1, 1, 10, 100 within training folds. `--permutations 199` regenerates stratified folds for each label permutation and writes the spectral permutation reference contrasts. These are separate from the neural label-randomization control.

Welch features use 200 Hz sampling, two-second periodic-Hann windows, 50% overlap, constant detrending and mean periodogram averaging. Bands are 1–4, 4–8, 8–13, 13–30 and 30–40 Hz; final 40-Hz bin is included. Bin power is summed and multiplied by 0.5 Hz, floored at 1e-12 before log10, then averaged over participant windows. Classical standardization and Ridge residualization use training data only. The common-frequency sensitivity splits beta at 20 Hz and jointly models the four lower bands or two higher bands, as specified in Online Resource 1.

## Separate early/late intervals

```sh
python analysis/core/temporal.py --input outputs/cache --data data/tdbrain --inventory outputs/metadata/inventory.csv --output outputs/temporal
```

This prepares thirteen four-second windows from 4–56 and 64–116 seconds, using the same continuous-record filter and four processing arms. Both intervals must pass the fixed gross-failure criteria. `COMPLETE.json` records eligible original participant indices. Arrays retain the full cohort axis and contain NaN outside the eligible set: restrict to `eligible_ids` before inference. This analysis evaluates saved models; it does not select new training intervals or refit models.

## Held-out transformation evaluation

Evaluate each participant with that participant's held-out, seed-1109, 30-epoch EEGNet checkpoint from `outputs/training`. The command checks the complete outer-fold training and test indices recorded in every checkpoint before evaluating any signal. It does not average source-fold models on source participants.

```sh
python analysis/core/evaluate_transforms.py --input outputs/cache --checkpoints outputs/training --mode common_removal --device cuda --output outputs/core_report/common_removal.json
python analysis/core/evaluate_transforms.py --input outputs/cache --checkpoints outputs/training --mode temporal --temporal outputs/temporal --device cuda --output outputs/core_report/temporal.json
```

The default checkpoint template is `fixed30_eegnet_{arm}_seed1109_split20261109_fold{fold}_epoch30.pt`, generated by the `core` plan and training commands above. A different equivalent filename layout can be supplied with `--checkpoint-template`, retaining `{arm}` and `{fold}` placeholders. Every checkpoint must contain its full `train_ids` and `test_ids`, state, positive training scale and epoch 30. An incorrect outer-fold checkpoint is rejected.

`common_removal` divides the linked-reference input by its saved training scale and subtracts the instantaneous 19-channel mean only at inference. Original and transformed inputs are evaluated together using the same saved model. It reports original and transformed discrimination, the transformed-minus-original AUC contrast and mean logit change for the two ocular-processing arms. This is a distribution-shift check, distinct from common-only or CAR retraining. The reported uncorrected linked-reference AUCs are 0.838 before removal and 0.526 after removal; their paired change is -0.312.

`temporal` consumes the separate early/late arrays prepared above. It selects the same eligible original participant indices for both intervals, applies each saved source scale, and evaluates thirteen windows per interval without fitting or recalibration. It reports early/late classification, late-minus-early AUC and mean probability change for all four processing arms. The reported uncorrected linked-reference AUCs are 0.836 early and 0.840 late (paired change 0.004). Explanation-rank and faithfulness comparisons use the separate explanation analyses.

Both output JSON files contain aggregate metrics, checkpoint hashes and conditional 2,000-replicate diagnosis-stratified participant intervals with seed 20261110. The paired draws are shared across transformations. These evaluations do not retrain models or estimate retraining uncertainty.

## Classification summaries

```sh
python analysis/core/report.py --input outputs/cache --plan outputs/core_plan.json outputs/sensitivity_plan.json --training outputs/training outputs/sensitivity_training --spectral outputs/spectral/oof_predictions.npz --output outputs/core_report
```

`classification.json` contains aggregate classifier metrics and paired reference contrasts, including the 155-person duration analysis and common-only retraining. It reports each initialization, all retained long-trajectory checkpoints and complete three-initialization probability ensembles. Incomplete groups are identified under `unavailable` and are not promoted to complete estimates. Classification intervals use 2,000 diagnosis-stratified participant bootstrap draws with seed 20261110; matched comparisons instead resample whole pairs. Common-only and duration AUC intervals preserve the positive-first draw ordering of their separate exploratory analysis; the duration contrast uses its explicitly resampled participant-index draws. The JSON contains no participant rows. It can be compared with the corresponding source-classification and exploratory common-component estimates in `results/aggregate.json`. Frequency-vector contrasts in Section S4 are high-two minus low-four and all-six minus low-four; the report preserves this direction.

The same command additionally writes `within_fold_auc.json`, a same-fold positive-negative-pair-weighted AUC sensitivity. See [the definition, calculation-only command and expected values](within_fold_auc.md).

## Dependencies

Metadata reconstruction requires pandas and openpyxl; signal preparation requires NumPy, SciPy and MNE; classical analyses require scikit-learn; neural training requires PyTorch. The reported neural runtime is PyTorch 2.0.1+cu118 with NumPy 1.26.4. Reproducing the published values requires the source data, complete requested model groups and matching analysis settings.
