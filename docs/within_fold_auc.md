# Within-fold AUC sensitivity

This supplementary calculation reaggregates saved held-out probabilities without training, calibration or score transformation. Pooled out-of-fold AUC compares scores across fitted fold models. Here, each positive-negative pair must belong to the same held-out fold. The overall estimate is `sum(n_positive * n_negative * fold_auc) / sum(n_positive * n_negative)`; tied scores contribute one half. The linked-mastoid minus common-average contrast uses the same pairs for both representations. All five folds are retained.

Folds share training participants and are not independent replicates. These are point estimates conditional on the existing fitted models, with no new confidence intervals or fold-level significance test. This calculation supplements the original pooled estimates.

## Recalculate from saved outputs

Use the cache, plans, per-job JSON files and spectral NPZ generated by the [core pipeline](core.md). The report reads `test_ids` and `logits_by_epoch` from each training result, converts logits to probabilities and averages probabilities across all three initializations for the main ensemble. Test indices from each plan define the corresponding alternative partition; `cache/folds.json` defines the original partition. Spectral inputs use `spectral_linked_basic` and `spectral_average_basic` in `oof_predictions.npz`.

```sh
python -B analysis/core/report.py --input outputs/cache --plan outputs/core_plan.json outputs/sensitivity_plan.json --training outputs/training outputs/sensitivity_training --spectral outputs/spectral/oof_predictions.npz --output outputs/within_fold_report --within-fold-only
```

The command writes aggregate-only `outputs/within_fold_report/within_fold_auc.json`. It does not fit models or calculate bootstrap intervals. Without `--within-fold-only`, the existing classification report also writes this additional file. Complete saved outputs are required for each comparison; missing groups appear under `unavailable` rather than being treated as complete estimates. No participant predictions are included in the released results.

Software checks require no participant data:

```sh
python -B -m unittest discover -s tests -p test_within_fold_auc.py -v
```

Checks cover direct positive-negative comparisons with ties and unequal pair counts, score offsets between folds, invalid partitions, incomplete groups, and the public saved-logit reporting route with three-initialization averaging.
